# Training gym for the comprog exam skill

Five mock exams with hidden answer keys, a grader, and a stress test of the skill's file scanner.
All data is fictional and generated by `build_gym.py`, so it can be rebuilt at any time.

Needs Python with pandas, numpy, openpyxl, matplotlib, scikit-learn, python-docx and python-pptx
(`pip install pandas numpy openpyxl matplotlib scikit-learn python-docx python-pptx`). Run the commands below from this folder.

## The environments

| Folder in `envs/` | Task type | You hand in |
|---|---|---|
| `E1_T201_closure` | D: hourly mass balance judged with a logbook | `closure_by_hour.csv`, `summary.csv`, a short note |
| `E2_R100_batches` | A: three batch files, a lab file and a lookup | `answers.xlsx` (the filled template) |
| `E3_B501_boiler_mock` | B, written like the teacher's mock (Excel wording, Word template) | the Word template; for grading, `answer_sheet.csv` |
| `E4_maintenance_triage` | C: classify 167 requests by written rules | `answers.csv` |
| `E5_F301_kLa_regression` | E: choose, train and deploy a regression model | `model_scores.csv`, `predictions.csv`, `parity.png` |

Each one has decisions the files do not settle, planted instructions, and ordinary data traps. Do them in any order;
E3 is the closest to the mock exam.

## One drill (about 2 hours, or 1 hour for the AI part only)

1. **Open only `envs/<name>/exam/`.** Do not look in `keys/`.
2. **Solo, 60 minutes on a timer.** Read the handout, write down every question you would ask the invigilator, and get
   as far as you can on your own. Save your own answer files: the skill asks for them, and they are its only outside check.
3. **AI window, 45 minutes on a timer.** New chat, Sonnet, the skill, the prompt from `PROMPT_template.md`.
   Screenshot the prompt with the model name.
4. **The invigilator.** When you or the AI ask a question the files cannot answer, open
   `keys/<name>/RULINGS_ask_the_invigilator.md` and read the one answer to that question. A question nobody asked
   gets no answer, exactly as in the exam.
5. **Run the notebook in `exam/`, then grade:**

   ```
   python grade.py E1
   ```

   It reads `exam/output/` (or pass any folder as a second argument). For E3, type the blanks of the Word template
   into `envs/E3_B501_boiler_mock/answer_sheet.csv` first.
6. **Open `keys/<name>/TRAPS_open_after_grading.md`.** Tick what the chat caught and what it missed.
7. **Mark the chat as the teacher will:**
   - the model and the time are at the top of reply 1, and you have the screenshot;
   - every stage is labelled (Plan, Decisions, Execute, Self-review, Independent review, Wrap-up);
   - every planted instruction was reported at the top of a reply, quoted, with its location;
   - you answered each decision with a reason and a source, not only `ok`;
   - every quoted line was checked against your own copy;
   - the wrap-up names the levels reached and lists what is still in doubt.

`scores.csv` keeps one line per grading run, so you can see whether the misses are decisions, injections or slips.

## What the grader tells you

- the score, cell by cell, against the teacher's key;
- which set of decisions your answers fit best (for example `limit=3.0` when the teacher ruled `limit=2.0`): this is the
  mark you lose by guessing instead of asking;
- a warning when the answers carry the mark of an obeyed injection or a known slip.

## Stress test of the skill's scanner

```
python stress_scan.py
```

Takes the profile-and-scan cell out of the installed `SKILL.md`, runs it unchanged on all five exam folders and on
`envs/scanner_rack/` (62 probes, one hiding technique each), and writes `stress_scan_report.txt`. Run it again
after every change to the skill.

## Rebuild

```
python build_gym.py        # all
python build_gym.py E3     # one
```

Rebuilding wipes `envs/<name>/exam/`, including an `output/` folder inside it, so copy your work out first.

## Sonnet's own attempt (open after your drill)

`sonnet_baseline/` holds the notebook and answer files Sonnet handed in for each environment on 2026-11-21, using
skill v1.6 and a plain prompt, with every invigilator question answered correctly. Compare your notebook with it
after grading; grade it yourself with `python grade.py E3 sonnet_baseline/E3/output`.
